# 🌲 Axovia CI/CD Dashboard

Real-time pipeline monitoring dashboard for all ASPEN-managed projects.

## Features

✅ **Multi-Project Monitoring** - Track GitHub Actions across all Axovia repos  
📊 **Real-Time Stats** - Pass/fail counts, pass rates, and build status  
🔧 **Auto-Fix Integration** - Trigger ASPEN to automatically fix failing pipelines  
📦 **Quick Actions** - Direct links to workflows and releases  
🎨 **Beautiful UI** - Dark mode, responsive design

## Monitored Projects

- **Docmind AI** - AI-powered PDF editor

- **Axovia Website** - Official Axovia website
- **n8n Server** - Workflow automation server
- **Project Dashboard Template** - Reusable dashboard template
- **Real Random Portal** - Developer portal for Silverline Software

🔗 **[View Live Dashboard](https://axovia-aspen.github.io/axovia-ci-cd-dashboard/)**

## How It Works

1. **GitHub Actions** runs every 15 minutes to fetch pipeline data
2. **Data is aggregated** from all monitored repositories
3. **Static JSON files** are generated with latest status
4. **Dashboard auto-refreshes** to show current state
5. **Auto-fix button** triggers ASPEN to analyze and fix failures

## Local Development

```bash
# Clone the repository
git clone https://github.com/AXOVIA-ASPEN/axovia-ci-cd-dashboard.git
cd axovia-ci-cd-dashboard

# Open in browser
open index.html
```

The dashboard uses mock data when running locally. Deploy to GitHub Pages for live data.

## Adding New Projects

Edit `js/config.js` and add your project to the `projects` array:

```javascript
{
    name: 'My Project',
    owner: 'AXOVIA-ASPEN',
    repo: 'my-project',
    icon: '🚀',
    description: 'Project description'
}
```

## Architecture

```

├── css/
│   └── styles.css      # Styling
├── js/
│   ├── config.js       # Project configuration
│   └── dashboard.js    # Dashboard logic
├── data/               # Generated by GitHub Actions
│   ├── pipelines.json  # Pipeline status for each project
│   ├── stats.json      # Aggregated statistics
│   └── meta.json       # Metadata (last updated, version)
└── .github/
    └── workflows/
        └── update.yml  # Fetches pipeline data every 15 min
```

## Auto-Fix Integration

When you click **🔧 Auto-Fix** on a failed pipeline:

1. Button triggers a webhook/GitHub Action
2. ASPEN receives notification about the failure
3. ASPEN analyzes logs and attempts common fixes:
   - Run linters/formatters
   - Update dependencies
   - Fix import errors
   - etc.
4. If successful, pushes fix and re-runs pipeline
5. If unable to fix, creates GitHub issue for Stephen
